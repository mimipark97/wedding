# 도레 릴스 스튜디오

아이폰 사파리에서 쓰는 9:16 릴스·쇼츠 영상 편집기 (단일 HTML 파일).

- 열기: https://mimipark97.github.io/wedding/dore-reels-studio/
- 소스: `index.html` 한 파일. 외부 의존은 폰트 CDN과, **얼굴 자동 추적을 켤 때만** 받는 AI 얼굴 감지 모델(MediaPipe tasks-vision, jsdelivr/Google CDN)뿐.

## 얼굴 블러 기능 (2026-11-27 추가)

- **✨ 얼굴 자동 추적**: 블러를 고르고 켜면 화면 속 얼굴(여러 명 포함)을 AI가 찾아 그 위에만 블러/모자이크가 따라붙습니다. 재생·MP4 내보내기에도 동일 적용. 모델을 못 받으면 안내 토스트가 뜨고 수동 블러로 그대로 쓸 수 있습니다.
- **📍 움직임 키프레임**: 수동 블러에 시간대별 위치·크기를 찍어 두면 프레임 사이를 부드럽게 보간해 따라갑니다. 타임라인 스티커·블러 줄에 ◇ 마커로 표시됩니다.
- **크기 조절 핸들**: 블러를 선택하면 미리보기 테두리에 동그란 핸들 4개가 생겨 손가락으로 바로 키우고 줄일 수 있습니다. 패널 맨 위에 블러 크기 / 가로 / 세로 / 강도 슬라이더가 바로 나옵니다.
- **자동저장 표시**: 상단에 `자동저장됨 HH:MM` 표시. 브라우저(IndexedDB)에 자동 저장되고, 다른 기기로 옮길 때는 `💾 저장`(.json, 미디어 포함) → `📂 복원`.

정적 GitHub Pages라서 폰↔PC 실시간 클라우드 동기화는 지원하지 않습니다(별도 서버 필요). 기기 간 이동은 저장 → 복원 파일로 합니다.
