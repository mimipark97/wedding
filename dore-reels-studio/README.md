# 도레 릴스 스튜디오

아이폰 사파리에서 쓰는 9:16 릴스·쇼츠 영상 편집기 (단일 HTML 파일).

- 열기: https://mimipark97.github.io/wedding/dore-reels-studio/
- 소스: `index.html` 한 파일. 외부 의존은 폰트 CDN과, **얼굴 자동 추적을 켤 때만** 받는 AI 얼굴 감지 모델(MediaPipe tasks-vision + BlazeFace, 약 2MB)뿐.

## 2026-11-27 밤 업그레이드 (bake 앱 스타일)

### 1. 얼굴 자동 추적 → "한 번 스캔 + 키프레임 베이킹"
- 예전에는 재생하는 동안 매 프레임 AI를 돌려 무거웠습니다. 이제는 토글을 켜면
  `얼굴 모델 불러오는 중…` → `영상 스캔 중 3/13…` 진행 배지가 뜨고,
  클립 구간을 **0.3초 간격으로 한 번만** 훑어 얼굴 위치를 키프레임으로 구워 둡니다.
- 구운 뒤에는 재생·편집·MP4 내보내기에서 **AI 추론 없이 보간만** 하므로 60fps로 부드럽게 따라갑니다.
- 사진 한 장은 감지 1회로 끝(2초 이내), 얼굴을 못 찾거나 네트워크가 막히면 원인 토스트가 뜹니다.
- 얼굴 검출은 전체 화면 + 가운데 + 사분면 배율로 훑어 작은 얼굴도 잡습니다.

### 2. 타임라인 줌 · 0.1초 정밀 분할
- 타임라인 위 `🔍− / 🔍＋ / 맞춤` 슬라이더, 두 손가락 핀치로 확대·축소(최대 30배).
- 최대 확대에서 **0.1초 눈금**과 0.05초 스냅, `◀0.1 / 0.1▶` 미세 이동, `✂️ 분할`.

### 3. 구간 선택 모달 (bake 스타일)
- 사진·영상을 한 개 불러오면 미리보기 + 노란 양쪽 핸들 트림 바가 뜹니다.
  `0:00 – 0:04 (소스 4.3초) · 재생 4.3초`, `직접 길이 조절`(시작/끝/길이 숫자 입력), `원본 그대로 넣기`.
- 클립의 `✂️ 구간 선택`으로 언제든 다시 조절. 사진은 0.5~15초(0.1초 단위).

### 4. 붙이기(PIP) — 사진 · 영상 · 스티커 · 텍스트
- 하단 `＋ 붙이기`(또는 스티커·블러 탭)에서 4가지를 고릅니다.
- 얹은 사진·영상은 이동·크기·회전·모서리 둥글기·불투명도·테두리·그림자·노출 구간을 조절하고,
  **붙인 영상은 재생과 MP4 내보내기에서 타임라인과 동기화**되어 함께 렌더됩니다.

### 5. 텍스트 편집 UI (bake 스타일)
- 선택 시 캔버스에 `↻ 회전` · `⤢ 크기` 핸들, 미니 바 `🗑 삭제 · ⧉ 복제 · ⋯ · 원하는 컷에 붙이기`.
- 좌측 세로 슬라이더 = 크기(pt), 우측 세로 슬라이더 = 자간 / 기울기 / 투명도 전환.
- 하단 검은 편집 바: `Aa 폰트 · 🎨 색 · 🖍 외곽선/그림자 · ≡ 정렬 · ☰ 줄간격 · ▢ 배경 박스`
  + `⌨ 키보드 | ✨ 모션` 탭(없음·쫀득·살포시·쾅·팝·아래에서 슥·타이핑·바운스·확대·축소, 반복 지원).
- 캔버스 `🔍` 1.5배 확대 토글.

### 그대로 유지
- 스티커·블러·모자이크·BGM·효과음·워터마크·프리셋·배속·전환 효과, 자동저장(IndexedDB), `💾 저장`/`📂 복원`(.json, 미디어 포함).
